# Aervane — native interface direction

**THESIS.** A small, precise macOS instrument: read CPU temperature and adjust the fan in the same menu-bar panel.

**OWN-WORLD.** Native AppKit, system glass on macOS 26+, SF text, custom airflow linework, muted mint in dark mode and spruce in light. The user's explicit native-macOS brief determines typography and material.

**STORY.** Temperature first; current control state and direct percentage adjustment second; editable presets immediately below. Setup, settings and editing remain inline. Requested and measured speed stay distinct.

**FIRST VIEWPORT.** A compact 380-point glass panel, one temperature figure, a modest live trend, Auto/Manual, the graduated dot-field slider, and three editable presets. A setup action appears only until fan control is connected.

**FORM.** seed:0325a3c4b8fee150. The user pinned native glass, an effort-style slider and purposeful microanimations. This is a code-led native build. The supplied Claude Code slider images are interaction references, not an approved whole-panel comp. No generated mockup is represented as a shipped screenshot.
